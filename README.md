# 사업기획부 전시참관노트 PWA v2

전시회 현장에서 부스별 인사이트를 빠르게 기록하고, 사진 여러 장과 녹음 메모를 함께 저장하는 모바일 우선 PWA입니다.

## v2 추가 기능

- 부스별 사진 여러 장 첨부
- 사진 미리보기 및 개별 삭제
- 부스별 녹음 메모
- 녹음 재생 및 개별 삭제
- 아이폰/갤럭시 모바일 화면 최적화

## GitHub Pages 업로드

1. 압축을 풉니다.
2. `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`, 아이콘 파일이 저장소 최상단에 오도록 업로드합니다.
3. GitHub 저장소 `Settings > Pages`로 이동합니다.
4. Source: `Deploy from a branch`
5. Branch: `main`, Folder: `/ root`
6. Save 후 생성된 GitHub Pages 주소에 접속합니다.

## 아이폰 설치

1. Safari에서 GitHub Pages 주소를 엽니다.
2. 공유 버튼을 누릅니다.
3. `홈 화면에 추가`를 선택합니다.
4. 홈 화면 아이콘으로 실행합니다.

## 녹음 관련 주의

- 녹음은 HTTPS 환경에서만 정상 동작합니다. GitHub Pages 주소는 HTTPS라 사용 가능합니다.
- Safari에서 처음 녹음할 때 마이크 권한을 허용해야 합니다.
- iOS 버전에 따라 녹음 형식이 다를 수 있습니다.
- 데이터는 기기 브라우저 저장소에 저장됩니다. 전시 후 JSON 백업을 권장합니다.

## 사진 관련 주의

- 여러 장을 선택할 수 있습니다.
- 앱이 자동으로 이미지를 압축해 저장합니다.
- 사진과 녹음이 많아지면 브라우저 저장소 용량을 초과할 수 있으므로, 장기간 사용 시 JSON 백업 후 불필요한 기록을 정리하세요.
